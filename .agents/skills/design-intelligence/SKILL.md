# DESIGN INTELLIGENCE SKILL

## PURPOSE

Create human-designed interfaces.
Avoid AI-generated UI patterns.

This skill controls:
- visual direction
- UX decisions
- design system
- UI review
- final polish


================================================

# PHASE 1 — DESIGN DIRECTION

Before writing code, analyze:


## 1. PRODUCT CONTEXT

Define:

- What is this product?
- Who uses it?
- What problem does it solve?
- What emotion should users feel?


Never design before understanding.


Example:

Bad:

"Create modern dashboard"

Good:

"Create running coach tool used outdoors during interval training."


================================================

# PHASE 2 — VISUAL STRATEGY


Define:

## Brand Personality

Choose:

- professional
- energetic
- premium
- playful
- editorial
- technical


Do not mix random styles.


================================================

# COLOR SYSTEM


Create:

Primary color:
Brand identity

Secondary:
Support

Accent:
Action only


Rules:

Maximum:
3 brand colors


Avoid:

- rainbow palette
- purple blue pink gradients
- neon everywhere
- AI default colors


================================================

# TYPOGRAPHY


Choose typography based on industry.


Avoid automatically:

Inter
Geist
Space Grotesk


Examples:


Sports:
Condensed bold typography


Finance:
Trustworthy typography


Luxury:
Elegant serif


Technology:
Clean geometric


================================================

# LAYOUT PRINCIPLES


Avoid:

AI default layouts:


- three feature cards
- endless cards
- bento grid without purpose
- centered hero with fake marketing copy


Prefer:

- clear hierarchy
- editorial composition
- asymmetric layouts
- strong focal point


================================================

# COMPONENT RULES


Every component must answer:

"Why does this exist?"


Remove:

- decorative icons
- sparkle
- random badges
- unnecessary labels


================================================

# ICON POLICY


Icons are functional.

Use only for:

- navigation
- status
- recognition


Never:

icon before every heading.


================================================

# MOTION POLICY


Animation must communicate:

- state change
- feedback
- navigation


Avoid:

- floating animation
- moving arrows
- endless hover effects


================================================

# AI DESIGN DETECTION


Before delivery check:


REMOVE:

[ ] purple + black AI style

[ ] glassmorphism

[ ] gradient buttons

[ ] glowing borders

[ ] dot grid background

[ ] floating blobs

[ ] fake testimonials

[ ] emoji decoration

[ ] excessive rounded cards

[ ] generic SaaS dashboard


================================================

# UX QUALITY CHECK


Verify:


Accessibility:

- contrast ratio acceptable
- readable typography
- touch target >48px


States:

- loading
- empty
- error
- success


================================================

# REVIEW MODE


When reviewing existing UI:


Do not redesign immediately.


First identify:


1. What works?

2. What feels generic?

3. What reduces usability?

4. What should be removed?


Then improve.


================================================

# FINAL PRINCIPLE


The goal is not:

"Make it beautiful."


The goal is:

"Make it feel designed specifically for this product."
